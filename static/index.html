Planet X × SPHEREx

Same sky. Same wavelength. Different time.

SPHEREx sees a star through a different colour on almost every visit. Pick a field and the lab finds the visits that match in wavelength, then compares only those.

This public copy shows recorded analyses of real SPHEREx data. They were produced by the same code as live runs and include full provenance. Live analysis of other targets needs the Python server, which runs locally; see the README.
